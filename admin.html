⚙️ 後端核心引擎架構配置

你可以隨時在 方案 A (Supabase) 與 方案 B (Google Apps Script) 之間無縫切換，兩者獨立運作，完全杜絕環境打架！

方案 A：Supabase (BaaS) 可選

Postgres 雲端資料庫，自帶 REST API 與 Auth，極速穩定，爬蟲批次匯入最方便。

方案 B：Google Apps Script 可選

以 Google 試算表作為輕量後端，免額外註冊第三方雲端，直覺查看儲存格。
